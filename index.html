Report+

Frontend para gestionar registros de horas y reportes con autenticación, filtros avanzados y exportación de información.

  • CRUD, paginación y filtros por empresa, usuario, tarea y fechas.
  • JWT con renovación automática y control de rutas.
  • Generación y descarga asíncrona de reportes Excel.
Vue 3QuasarPiniaAxiosElectron
Cómo lo resolví+
El problema
Centralizar registros de horas y convertir una selección por empresa, persona o fecha en un reporte.
Mi aporte
Desarrollé el frontend para crear, editar y consultar registros, aplicar filtros y solicitar reportes.

Un cliente con CRUD, filtros y descarga de Excel conectado a una API. La demo de abajo permite probar una versión acotada del flujo con datos ficticios.

    Multi-Market

    Marketplace que organiza múltiples tiendas, sus catálogos y productos mediante una API Django y un cliente Vue.

    • Usuarios, tiendas, categorías, subcategorías y productos.
    • Búsqueda, filtros por tienda y categoría, y descuentos.
    • Frontend desacoplado que consume la API mediante Axios.
    Django RESTVue 3VuexJWT
    Cómo lo resolví+
    El problema
    Organizar tiendas y catálogos en una plataforma común, con productos que puedan buscarse y filtrarse.
    Mi aporte
    Trabajé en la API del catálogo y en el cliente que presenta tiendas, categorías y productos.
    La decisión técnica
    Desacoplé el backend Django REST del frontend Vue, con Axios como punto de comunicación.
    El resultado
    Dos proyectos complementarios: una API para el catálogo y una interfaz para explorarlo por tienda y categoría.
